## Pourquoi CtxFirst ?

<CardGrid stagger>
  <Card title="Étape par étape" icon="list-format">
    Décomposez un workflow LLM en étapes explicites plutôt qu'un seul gros
    prompt opaque.
  </Card>
  <Card title="Validations humaines" icon="approve-check">
    Insérez des points de contrôle aux moments clés : l'humain valide ou corrige
    avant de continuer.
  </Card>
  <Card title="Boucles de feedback" icon="random">
    Itérez sur une étape sans tout relancer — le contexte des étapes précédentes
    est préservé.
  </Card>
  <Card title="Extensible par plugins" icon="puzzle">
    Étendez l'app via des plugins (Kanban, Linear, …) construits avec le
    `@ctxfirst/plugin-sdk`.
  </Card>
</CardGrid>
