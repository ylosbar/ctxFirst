## Why CtxFirst?

<CardGrid stagger>
  <Card title="Step by step" icon="list-format">
    Break an LLM workflow into explicit steps instead of one big opaque
    prompt.
  </Card>
  <Card title="Human validations" icon="approve-check">
    Insert checkpoints at key moments: a human approves or corrects before
    moving on.
  </Card>
  <Card title="Feedback loops" icon="random">
    Iterate on a step without rerunning everything — the context from previous
    steps is preserved.
  </Card>
  <Card title="Extensible via plugins" icon="puzzle">
    Extend the app with plugins (Kanban, Linear, …) built with the
    `@ctxfirst/plugin-sdk`.
  </Card>
</CardGrid>
