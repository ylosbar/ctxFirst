CtxFirst is a desktop application (Electron) for **driving LLM workflows step by step**, with **human validations** at key moments and **feedback loops** that let you iterate without starting over.

## Key concepts

- **Workflow** — a sequence of steps orchestrating one or more LLM calls.
- **Step** — a unit of work, which may require a human validation before moving to the next one.
- **Human validation** — a checkpoint where you approve, edit, or reject the result of a step.
- **Feedback loop** — the ability to rerun a step with feedback, without losing the accumulated context.
- **Plugin** — an extension that adds capabilities to the app (see [Plugins](/en/plugins/overview/)).
