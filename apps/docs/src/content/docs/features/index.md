## Fonctionnalités

- **Workflows étape par étape** — décomposition d'un objectif en étapes orchestrées.
- **Validations humaines** — points de contrôle avant progression.
- **Boucles de feedback** — itération sur une étape avec contexte préservé.
- **Système de plugins** — voir [Plugins](/plugins/overview/).

> À détailler : pour chaque fonctionnalité, créer une page dédiée dans `src/content/docs/features/` (elle apparaîtra automatiquement dans la sidebar).
